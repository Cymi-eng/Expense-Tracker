# Expense Tracker

## Project Overview

The Expense Tracker is a web application built using HTML, CSS, and JavaScript that helps users manage their daily expenses. Users can add, view, filter, and delete expenses while tracking their total spending. The application stores data in Local Storage, ensuring expenses remain available even after refreshing the page.

---

## Features

* Add a new expense with description, amount, and category.
* View all recorded expenses.
* Delete expenses from the list.
* Calculate total expenses automatically.
* Filter expenses by category.
* Store expenses using Local Storage.
* Object-Oriented Programming (OOP) implementation.
* Unit testing with Jest.

## Installation

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate into the project directory:

```bash
cd expense-tracker
```

---

## Running the Application

Open the `index.html` file in your browser.

Or use VS Code Live Server:

1. Install the Live Server extension.
2. Right-click `index.html`.
3. Select **Open with Live Server**.

---

## Running Tests

Run Jest tests using:

```bash
npm test
```

The tests cover:

* Adding expenses
* Removing expenses
* Calculating total expenses
* Filtering expenses by category


## Deployment

The application is deployed using GitHub Pages.

### Steps

1. Push the project to GitHub.
2. Open the repository.
3. Navigate to Settings → Pages.
4. Select the main branch.
5. Save changes.
6. Access the generated GitHub Pages URL.
